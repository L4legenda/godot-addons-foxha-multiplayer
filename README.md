# Foxha Playground

Тестовая сетевая арена на Godot 4.7 для 2–8 игроков. Браузер и Windows
используют один API и общий протокол `playground-1`.

Страница игры: https://games.foxha.ru/games/foxha-playground

## Подключение

1. Откройте проект в Godot и нажмите F6 для `prototype/prototype.tscn` либо F5.
   Для native сначала установите зависимость:
   `powershell -ExecutionPolicy Bypass -File scripts/install-webrtc.ps1`.
   Готовая Windows-сборка содержит DLL рядом с EXE: переносите всю папку.
2. В открывшемся оверлее войдите в Foxha или зарегистрируйтесь.
   Подтверждение почты выполняется кодом внутри игры.
3. Первый игрок создаёт лобби с доступом **«По коду»** и копирует его кнопкой
   на арене. Остальные входят в свои аккаунты и вводят этот код.
4. Закройте оверлей через Shift+Tab. WASD / стрелки — движение,
   Space — цветной импульс, видимый другим игрокам.

Для двух окон нужны **два разных аккаунта**. Вход одним аккаунтом в нескольких
окнах не создаёт независимых игроков. При выходе хоста лобби закрывается.
Пока проверяется сетевой прототип: сражений, матчмейкинга и сохранения прогресса нет.

Проект уже настроен на `https://games.foxha.ru` и игру
`479ac58f-9231-4746-b04b-0057548509a8`. Для своей игры поменяйте публичный UUID
в Project Settings → Foxha Multiplayer. Это не секретный код владельца.

## Устройство

Хост рассчитывает движение и ограничивает скорость/границы арены. Гости
отправляют направление, а хост возвращает снимки состояния 20 раз в секунду.
Отсутствие ввода более 500 мс останавливает игрока. Клиенты сглаживают движение.
Имена и импульсы передаются RPC. Соединение может идти через coturn,
если прямой маршрут недоступен. Старая одиночная 3D-сцена сохранена в main.tscn.

Закреплённый webrtc-native использует TURN по UDP. В сетях, полностью
блокирующих UDP, используйте браузерную сборку с TURN TCP/TLS; для native
потребуется другая сборка WebRTC с поддержкой этих транспортов.

Редакторский MCP не включён в экспортируемый проект; при необходимости
включите установленный локально плагин Godot MCP в редакторе.

## Сборка

Создайте каталоги builds/windows и builds/web, затем:

```sh
godot --headless --path . --export-release "Windows Desktop" builds/windows/FoxhaPlayground.exe
godot --headless --path . --export-release Web builds/web/index.html
```

Для готовых ZIP с лицензиями зависимостей используйте
`scripts/export-prototype.ps1 -Godot <путь к Godot>`.

Web-сборку загружайте целиком на страницу этой игры в Foxha: ей нужен
postMessage-мост родительской страницы. Простое открытие index.html с диска
не обеспечивает авторизацию и лобби. Экспортные шаблоны должны совпадать
с версией Godot. Native DLL устанавливаются отдельно и не хранятся в Git.
